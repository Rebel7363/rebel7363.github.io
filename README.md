# Rajhansh Yadav - Portfolio

Folder: `index.html` (the site) + `assets/` (videos, avatar, favicon, social image). Keep them together.

## See it on your computer
Unzip, then double-click `index.html` (use Chrome).

## Edit it
Open the folder in VS Code (free). Press Ctrl+F and search for: `to be filled`, `coming soon`, `Resume`, `YOUR-SITE-URL`.

## Put it online (free, GitHub Pages)
1. Create a public repo named `rebel7363.github.io` on github.com (all lowercase).
2. Click "uploading an existing file", drag in `index.html` and the whole `assets` folder, then Commit.
3. Repo Settings -> Pages -> Source: Deploy from a branch -> `main` / root -> Save.
4. After ~1 minute your site is at https://rebel7363.github.io
5. Replace `YOUR-SITE-URL` in `index.html` (the og:image line) with `rebel7363.github.io`, commit again.
